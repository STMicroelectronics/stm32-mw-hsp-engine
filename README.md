## Overview

This repository provides the STM32Cube **HSP Engine** Middleware Library, **common to every** STM32Cube MCU firmware that supports it.

## Compatibility information

Please refer to the **release note** in the firmware repository for the STM32 series you are using (see the list in the _STM32Cube MCU Offer_). It is **important** to use a **consistent set** of software versions as specified.

> [!IMPORTANT]
> The preprocessing directive `USE_HAL_HSP_CUBE1_LEGACY` must be defined in the compilation options.
